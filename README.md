# AI Tech Companies are Selling Our Future for a Profit

A self-contained pixel-art browser game. Press the red button to trigger a fictionalized data-center target sequence across a bleak U.S. map.

## Run locally

Open `index.html` in a browser, or run:

```sh
npm run dev
```

## Deploy to Vercel

Import the GitHub repository into Vercel. No build settings or environment variables are required.

## Notes

The map uses broad regional, fictionalized data-center labels. Sound effects are synthesized in the browser; no audio assets are downloaded.
